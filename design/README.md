# Design — identidade visual

Brand Book do CPAT Campinas (conceito "Oportunidades que conectam pessoas"), em arquivos de canvas `.dc.html` do Claude Design. Eles foram exportados do artefato e abrem no Claude Design, não direto no navegador.

| Arquivo | Conteúdo |
| --- | --- |
| `Main.dc.html` | Capa |
| `Conceito.dc.html` | Conceito e pilares |
| `Logotipo.dc.html` | Evolução e versões do logo (usa a imagem do logo original, que não está neste repositório) |
| `Cores.dc.html` | Paleta e contrastes |
| `Tipografia.dc.html` | Sora e Inter |
| `Elementos.dc.html`, `Ilustracoes.dc.html`, `Icones.dc.html` | Elementos gráficos, ilustrações e ícones |
| `AplicacoesA.dc.html`, `AplicacoesB.dc.html` | Aplicações da marca |
| `canvas.json` | Posição das pranchas no canvas |
