# Roadmap

## v1 — Front-end

1. Projeto Angular com Tailwind (feito).
2. Tokens, componentes base e layout base.
3. Home, Vagas, Serviços, Institucional e Atendimento.
4. Mobile, VLibras, SEO e página 404.
5. Docker com Nginx e JSON Server.
6. Testes (Vitest e Playwright) e CI.
7. Auditoria de acessibilidade e testes com usuários.

## v2 — Back-end

- API de vagas e envio real de SAC e Ouvidoria.
- Integração com o Emprega Brasil.
- Banco PostgreSQL a partir do modelo de dados.
- Painel administrativo ou CMS.

Acompanhe o andamento nas [issues](https://github.com/Paul0Ant0ni0/cpat-digital/issues).
